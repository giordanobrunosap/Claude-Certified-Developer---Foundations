# Claude Certified Developer – Foundations: Drill v3

Pagina HTML con il drill di preparazione. È un singolo file (`index.html`), funziona offline: basta aprirlo nel browser.

## Online

Dopo l'attivazione di GitHub Pages:
https://giordanobrunosap.github.io/Claude-Certified-Developer---Foundations/

## Scaricarlo e usarlo in locale

Non serve un account GitHub.

### Opzione 1 – Solo il file (la più semplice)

1. Apri [`index.html`](index.html) qui su GitHub.
2. Clicca l'icona di download (freccia verso il basso) in alto a destra sul file.
3. Fai doppio clic sul file scaricato: si apre nel browser.

### Opzione 2 – Tutto il repo come ZIP

1. Dalla pagina principale del repo clicca **Code** → **Download ZIP**.
2. Decomprimi lo ZIP.
3. Apri `index.html` con doppio clic.

### Opzione 3 – Con git

```bash
git clone https://github.com/giordanobrunosap/Claude-Certified-Developer---Foundations.git
cd Claude-Certified-Developer---Foundations
```

Poi apri `index.html` nel browser.
